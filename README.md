## Overview

Goodhertz Tone Control models the simplicity and musicality of vintage hi-fi tone controls, offering shelving EQ curves that interact in a naturally pleasing way.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Tone Control** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Bass Shelf** | Wide low-shelf boost/cut centered in the 60–200 Hz range |
| **Treble Shelf** | High-shelf boost/cut for presence and air above 5 kHz |
| **Fletcher-Munson** | Contour mode applies equal-loudness compensation at low volumes |
| **Analog Character** | Non-linear interactions between bass and treble as in real circuits |
